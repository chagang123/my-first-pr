# 拼多多自动上架

客户：五金紧固件，两个拼多多店铺。资料是店透视从同行导出的 zip（表格 + 主图 + SKU 图 + 详情图），标题和图片照原样上。

## 文件

| 文件 | 干什么 |
|---|---|
| `loader.py` | 读店透视导出的资料，zip 会自动解压；SKU 图按文件名对到 SKU |
| `main.py` | `python main.py 检查 <文件夹>` 出检查报告；上架功能等采集完发布页再写 |
| `capture.py` → `dist/页面采集.exe` | 第一次远程用：客户登录后台，走一遍发布流程，每一步存下网页、截图、按钮输入框列表和提交请求 |
| `browser.py` | 像普通人一样启动 Edge 再连上去（Playwright 直接启动会被拼多多弹滑块） |
| `设置.json` | 店铺、每天上限、间隔、价格来源/公式、标题长度、默认属性、运费模板 |

## 进度

- [x] 资料读取 + 检查报告（样例：66 个 SKU、66 张 SKU 图全部对上）
- [x] 页面采集 exe（自己电脑上测过：能打开扫码登录页、能保存、能正常关掉 Edge）
- [ ] 第 1 次远程：采集发布页
- [ ] 写上架流程（选类目 → 标题 → 主图 → 详情图 → 属性 → SKU 表 → 提交前核对 → 提交）
- [ ] 第 2 次远程：安装、真实商品试上、教客户用

## 第 1 次远程要采集的步骤

按顺序，每一步在黑窗口输入名字回车：

1. 登录后首页
2. 点「发布新商品」后的选类目页
3. 选好紧固件类目后的发布页（还没填任何东西）
4. 填完标题、传完主图
5. 点开详情图上传
6. 属性区全部展开
7. 加一个规格、填两三个规格值以后的 SKU 表
8. 运费模板、发货时间那一块
9. 填满一个真实商品、点提交之前
10. 点提交以后（成功或报错页面）

第 9、10 步用客户真实的商品，上完让客户决定留不留。提交时的请求会记在 `提交请求.jsonl` 里。
