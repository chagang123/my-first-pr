# my-first-pr

A small practice repository for learning the GitHub pull request workflow.

## Getting started

Clone the repository:

```bash
git clone https://github.com/chagang123/my-first-pr.git
cd my-first-pr
```

## Making a change

1. Create a branch: `git checkout -b my-change`
2. Edit files and commit: `git commit -am "Describe the change"`
3. Push the branch: `git push -u origin my-change`
4. Open a pull request: `gh pr create`
